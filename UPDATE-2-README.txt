CyberZone Academy — Navigation and Heading Update 2.0

Approved changes:
1. Topic headings show official topic number and title together.
2. Bottom topic navigation uses compact number-only rounded buttons.
3. Practical headings show "Practical N: " followed by the official title.
4. Practical pages display the subject name centered above the heading.
5. Bottom practical navigation uses compact "Practical N" rounded buttons.
6. Bottom navigation buttons have visibly tinted blue-gray backgrounds in light mode and clear navy backgrounds in dark mode. Back buttons retain their existing tinted background.

All syllabus/practical data is unchanged. Navigation remains restricted to the current subject. Previous/next links are hidden at boundaries.

To run: open this folder in VS Code, then run npm install (first time only), then npm run dev. Keep the terminal running and open the Local URL displayed.
